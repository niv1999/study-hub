מודול 03 ↗

מספרים שלמים חיוביים שכל אחד מייצג מצב כישלון מוגדר, עם שם סמלי שמתחיל באות 'E' ומוגדר ב-errno.h: ‏1=EPERM, ‏2=ENOENT (קובץ לא נמצא), 4=EINTR, ‏11=EAGAIN, ‏13=EACCES (הרשאה נדחתה), 22=EINVAL. ההגדרות המספריות בפועל מגיעות מכותרי הליבה (asm-generic/errno-base.h).

מודול 03 ↗

קריאת המערכת שמחליפה את התהליך בתוכנית חדשה: הקרנל מאמת את ה-ELF Header, מוחק ומאפס לחלוטין את מרחב הזיכרון הישן שהועתק ב-fork, טוען את הקטעים הבינאריים, בונה Stack עם argv ומשתני הסביבה, ומאפס את ה-Instruction Pointer לנקודת הכניסה של התוכנית.

מודול 04 ↗

exit() / _exit()תהליכים

סיום התהליך: exit() מבצעת קודם את ניקוי ספריית ה-C (שטיפת מאגרי stdio והרצת פונקציות שנרשמו ב-atexit) ואז קוראת ל-_exit(), שהיא קריאת המערכת שמסיימת את התהליך ומשחררת את משאביו. בשיעור: היציאה יכולה להיות יזומה (קריאה ל-exit) או לא יזומה (exception, או signal מתהליך אחר).

מודול 08 ↗

מספר קטן (0–255) שהתהליך מוסר בסיומו — 0 מציין הצלחה וכל ערך אחר כישלון, ומכאן התבנית exit(EXIT_FAILURE) אחרי כישלון קריאת מערכת. הקרנל שומר אותו עד שהאב קורא ל-wait()/waitpid() ובודק אותו במאקרו WIFEXITED / WEXITSTATUS; העברת NULL כארגומנט הסטטוס אומרת שהאב אינו מתעניין בו.
