לפני שמתחילים

זהו מבחן תרגול מקורי שנכתב לאתר, במתכונת המדויקת של מבחני האמת של ד"ר סעד: 5 שאלות פתוחות חישוביות לפי "תבנית חמש המשבצות" הקבועה, עם 2–4 סעיפים לכל שאלה. השאלות והמספרים חדשים — הפתרונות הם פתרונות האתר.

  • משך מומלץ: 3 שעות (במועדים האמיתיים: שעתיים עד 3 שעות).
  • חומר עזר: מותר — נוסחאון, הטבלאות הסטטיסטיות ומחשבון. עונים על כל השאלות.
  • איך לתרגל נכון: פתרו כל סעיף עד הסוף על דף, הקלידו את התשובה הסופית בתיבת הבדיקה — ורק אז פתחו את הפתרון המלא. אל תחשפו פתרון לפני שניסיתם.

הטבלאות להורדה: טבלת Φ(z) · טבלת t · טבלת χ² (גרסאות HTML מלאות — בעמוד חוברת התרגילים + טבלאות).

שאלה 1

להלן התפלגות זמני הרכבה בדקות של ארון על ידי פועלי מפעל רהיטים מסוים:

זמן הרכבה (דקות)40 – 4646 – 5252 – 5858 – 6464 – 70
מס' פועלים1535503515

סעיף א

מצא זמן הרכבה ממוצע וזמן הרכבה חציוני של ארון במפעל. מהו העשירון התשיעי?

ממוצע. עובדים עם אמצעי המחלקות: 43, 49, 55, 61, 67 (סה"כ n = 150 פועלים):

x̄ = Σf·x / n = (15·43 + 35·49 + 50·55 + 35·61 + 15·67) / 150

x̄ = (645 + 1715 + 2750 + 2135 + 1005) / 150 = 8250 / 150 = 55

אפשר גם בלי לחשב: ההתפלגות סימטרית סביב המחלקה 52–58, ולכן הממוצע הוא אמצע המחלקה המרכזית — 55 דקות.

חציון. מיקום החציון: n/2 = 75. שכיחויות מצטברות: 15, 50, 100 — כלומר התצפית ה-75 נמצאת במחלקה 52–58 (רוחב w = 6, שכיחות 50, מצטבר קודם 50):

Md = 52 + ((75 − 50) / 50)·6 = 52 + 3 = 55

בהתפלגות סימטרית החציון שווה לממוצע — ביקורת הגיון שעברה.

עשירון תשיעי. מיקום: 0.9·150 = 135. המצטבר עד 58 הוא 100, לכן הנקודה במחלקה 58–64:

D9 = 58 + ((135 − 100) / 35)·6 = 58 + 6 = 64

90% מהפועלים מרכיבים ארון בפחות מ-64 דקות.

סעיף ב

מצא סטיית תקן וטווח בין-רבעוני עבור זמן ההרכבה של ארון.

סטיית תקן. אלה כל פועלי המפעל — אוכלוסיה, ולכן השונות מחולקת ב-n (לא ב-n−1). נוח לעבוד עם הסטיות מהממוצע 55: הסטיות הן ‎−12, −6, 0, 6, 12‎:

σ² = Σf·(x − x̄)² / n = (15·144 + 35·36 + 0 + 35·36 + 15·144) / 150

σ² = (2160 + 1260 + 0 + 1260 + 2160) / 150 = 6840 / 150 = 45.6

σ = √45.6 ≈ 6.75

טווח בין-רבעוני. רבעון ראשון — מיקום 0.25·150 = 37.5, במחלקה 46–52 (מצטבר קודם 15, שכיחות 35):

Q₁ = 46 + ((37.5 − 15) / 35)·6 = 46 + 3.857 = 49.86

רבעון שלישי — מיקום 0.75·150 = 112.5, במחלקה 58–64 (מצטבר קודם 100):

Q₃ = 58 + ((112.5 − 100) / 35)·6 = 58 + 2.143 = 60.14

IQR = Q₃ − Q₁ = 60.14 − 49.86 = 10.29

50% הפועלים "המרכזיים" נמצאים בטווח של כ-10.29 דקות.

סעיף ג

אם זמן ההרכבה החדש יהיה 80% מזמן ההרכבה הקודם ועוד 3 דקות, עבור כל פועל, קבע מבלי לחשב מחדש ממוצע וסטיית תקן חדשים. הוכח או הסבר קביעתך.

זו טרנספורמציה לינארית: Y = 0.8X + 3. לפי תכונות הטרנספורמציה:

ȳ = a·x̄ + b = 0.8·55 + 3 = 47

S_y = |a|·S_x = 0.8·6.75 ≈ 5.40

הקבוע 3 מזיז את כל התצפיות יחד ולכן משפיע רק על הממוצע; המקדם הכפלי 0.8 "מכווץ" גם את המרחקים מהממוצע — ולכן משפיע גם על סטיית התקן.

הוכחה. אם yᵢ = a·xᵢ + b אז:

ȳ = Σ(a·xᵢ + b)/n = a·Σxᵢ/n + b = a·x̄ + b

yᵢ − ȳ = a·xᵢ + b − (a·x̄ + b) = a·(xᵢ − x̄)

S_y² = Σ(yᵢ − ȳ)²/n = a²·Σ(xᵢ − x̄)²/n = a²·S_x² ⇒ S_y = |a|·S_x

הקבוע b מתבטל בחיסור — ולכן אינו משפיע על הפיזור.

שאלה 2

מפעל מייצר גופי עטים ומילויים באופן בלתי תלוי. אחוז הגופים הלקויים 10 ואחוז המילויים הלקויים 20. מרכיבים עטים מגוף ומילוי, כאשר עט תקין מחייב גוף ומילוי תקינים, אחרת העט פגום. מרכיבים 4 עטים. מה ההסתברות לאפשרויות הבאות:

סעיף א

4 עטים תקינים.

שלב מקדים — ההסתברות שעט בודד תקין. גוף ומילוי בלתי תלויים, ולכן לפי חוק הכפל:

p = P(גוף תקין)·P(מילוי תקין) = 0.9·0.8 = 0.72

ומכאן ההסתברות שעט בודד פגום: q = 1 − 0.72 = 0.28.

שלב שני — בינומית על 4 עטים. ההרכבות בלתי תלויות: X ~ Bin(4, 0.72).

P(X=4) = 0.72⁴ = 0.2687

סעיף ב

לפחות 2 עטים תקינים.

"לפחות 2" — הכי קצר דרך המשלים: מחסירים את P(0) ואת P(1):

P(X=0) = 0.28⁴ = 0.0061

P(X=1) = C(4,1)·0.72·0.28³ = 4·0.72·0.02195 = 0.0632

P(X≥2) = 1 − 0.0061 − 0.0632 = 0.9306

סעיף ג

רק 2 עטים תקינים.

בדיוק 2 מתוך 4 — הנוסחה הבינומית המלאה, כולל המקדם C(4,2) = 6:

P(X=2) = C(4,2)·0.72²·0.28² = 6·0.5184·0.0784 = 0.2439

סעיף ד

לכל היותר 2 עטים תקינים.

"לכל היותר 2" = 0 או 1 או 2. אפשר לסכם ישירות (יש כבר את כל האיברים):

P(X≤2) = P(0) + P(1) + P(2) = 0.0061 + 0.0632 + 0.2439 = 0.3132

או דרך המשלים, עם P(X=3) = C(4,3)·0.72³·0.28 = 4·0.3732·0.28 = 0.4180:

P(X≤2) = 1 − P(3) − P(4) = 1 − 0.4180 − 0.2687 = 0.3132

שתי הדרכים נותנות אותה תוצאה — ביקורת חישוב מצוינת למבחן.

שאלה 3

בכד 4 כדורים ירוקים ו-2 צהובים. שולפים ללא החזרה כדור תמורת 200 ש"ח לשליפה, וזוכים ב-1000 ש"ח כאשר הכדור צהוב ואז מפסיקים; אחרת ממשיכים עד לזכיה.

סעיף א

רשום את פונקציית ההסתברות של מספר הכדורים הירוקים הנשלפים, ובדוק שסכום ההסתברויות הוא 1. מה ההסתברות שיישלפו בדיוק 2 כדורים ירוקים?

שליפה ללא החזרה מכמות קטנה — אסור בינומית! בונים את הפונקציה ידנית בשרשרת הסתברויות מותנות. X = מספר הירוקים הנשלפים לפני הצהוב הראשון:

P(X=0) = 2/6 = 5/15 ≈ 0.333

P(X=1) = (4/6)·(2/5) = 4/15 ≈ 0.267

P(X=2) = (4/6)·(3/5)·(2/4) = 3/15 = 0.2

P(X=3) = (4/6)·(3/5)·(2/4)·(2/3) = 2/15 ≈ 0.133

P(X=4) = (4/6)·(3/5)·(2/4)·(1/3)·(2/2) = 1/15 ≈ 0.067

ביקורת: הסכום —

(5 + 4 + 3 + 2 + 1) / 15 = 15/15 = 1 ✓

שימו לב לתבנית היפה: P(X=k) = (5−k)/15. התשובה לבדיוק 2 ירוקים: 0.2.

סעיף ב

חשב תוחלת ושונות של מספר הכדורים הירוקים הנשלפים.

E(X) = Σx·p = (0·5 + 1·4 + 2·3 + 3·2 + 4·1) / 15 = 20/15 = 4/3 ≈ 1.33

Σx²·p = (0·5 + 1·4 + 4·3 + 9·2 + 16·1) / 15 = 50/15 = 10/3

V(X) = Σx²·p − [E(X)]² = 10/3 − 16/9 = 14/9 ≈ 1.56

ביקורת הגיון: רוב הכדורים ירוקים (4 מתוך 6), ולכן בממוצע נשלף יותר מירוק אחד לפני הצהוב — התוחלת 1.33 הגיונית.

סעיף ג

חשב את תוחלת הזכיה נטו של שחקן במשחק זה (הזכיה בניכוי התשלום על השליפות) ואת השונות שלה.

מספר השליפות הוא X + 1 (כל הירוקים ועוד הצהוב העוצר). הזכיה נטו W היא טרנספורמציה לינארית של X:

W = 1000 − 200·(X + 1) = 800 − 200X

E(W) = 800 − 200·E(X) = 800 − 200·(4/3) = 800 − 266.67 = 533.33

V(W) = 200²·V(X) = 40000·(14/9) ≈ 62222.22

הקבוע 800 אינו משפיע על השונות — רק המקדם ‎−200‎, שנכנס בריבוע.

סעיף ד

מה צריכים להיות דמי הכניסה (מעבר לתשלום על שליפת כל כדור), כך שתוחלת הרווח של מארגן המשחק תהיה 150 ש"ח?

רווח המארגן הוא בדיוק מינוס הזכיה נטו של השחקן, ועוד דמי הכניסה d:

E(רווח) = d − E(W) = d − 533.33

d − 533.33 = 150 ⇒ d = 683.33

כלומר דמי כניסה של כ-683.33 ש"ח (בפועל המארגן יעגל כלפי מעלה).

שאלה 4

משך הפעולה של מצבר נטען מתפלג נורמלית עם ממוצע 600 שעות והשונות 2500.

סעיף א

נבחר מצבר אקראי. מה ההסתברות שמשך פעולתו יהיה: I. מעל 675 שעות. II. בדיוק 600 שעות.

מלכודת ראשונה: נתונה שונות 2500 — סטיית התקן היא השורש:

σ = √2500 = 50

I. מתקננים ל-ציון תקן וקוראים בטבלת Φ:

z = (675 − 600) / 50 = 1.5 ⇒ Φ(1.5) = 0.9332

P(X > 675) = 1 − 0.9332 = 0.0668

II. משך פעולה הוא משתנה רציף — ההסתברות לערך בודד מסוים היא תמיד 0 (שטח של תחום ברוחב אפס). זהו סעיף מלכודת מוכר ממבחן תשע"א ("בדיוק 180 ס"מ").

סעיף ב

מה הטווח הבין-רבעוני של משך הפעולה של המצברים?

בשאלה הפוכה: השטח עד הרבעון השלישי הוא 0.75, ובטבלה z(Φ=0.75) = 0.675; הרבעון הראשון סימטרי — z = −0.675:

Q₃ = 600 + 0.675·50 = 633.75

Q₁ = 600 − 0.675·50 = 566.25

IQR = 633.75 − 566.25 = 1.35·σ = 1.35·50 = 67.5

הדרך הקצרה של המרצה: בכל התפלגות נורמלית המרחק בין הרבעונים הוא 1.35 סטיות תקן.

סעיף ג

נלקח מדגם של 25 מצברים. מה ההסתברות שממוצע משך הפעולה במדגם יהיה מתחת ל-584 שעות?

עוברים להתפלגות ממוצע המדגם: התוחלת נשארת 600, אבל סטיית התקן מתכווצת:

σ/√n = 50/√25 = 50/5 = 10

z = (584 − 600) / 10 = −1.6

P(x̄ < 584) = Φ(−1.6) = 1 − Φ(1.6) = 1 − 0.9452 = 0.0548

המלכודת הקלאסית: לשכוח את החלוקה ב-√n ולתקנן עם 50 — היינו מקבלים z = −0.32 ותשובה שגויה לגמרי.

סעיף ד

נלקח מדגם של 100 מצברים ונתקבל ממוצע 590 שעות. בנה רווח סמך ברמת בטחון 95% למשך הפעולה הממוצע של כלל המצברים. מהי טעות הדגימה ומהו הגבול העליון של הרווח?

שונות האוכלוסיה ידועה (2500) — ולכן עובדים עם Z ולא עם t. רווח סמך הוא תמיד דו-צדדי: ברמת בטחון 95% קוראים z(0.975) = 1.96.

A = z·σ/√n = 1.96·50/√100 = 1.96·5 = 9.8

x̄ ± A = 590 ± 9.8 ⇒ (580.2, 599.8)

ברמת בטחון 95%, משך הפעולה הממוצע של כלל המצברים נמצא בין 580.2 ל-599.8 שעות.

שאלה 5

סעיף א

סטיות התקן של ציוני מכינה א' ומכינה ב' הן בהתאמה 20 ו-15. תלמידי מכינה ב' טוענים שציוני תלמידי מכינה א' גבוהים יותר. לבדיקת טענה זו נלקח מדגם מקרי של 100 תלמידים ממכינה א' עם ממוצע 72, בעוד שמדגם של 100 תלמידי מכינה ב' הראה ממוצע של 66. בדוק את טענת תלמידי מכינה ב' ברמת מובהקות של 5%, תוך ניסוח של ההשערות והסבר מתאים.

ניסוח ההשערות. הטענה הנבדקת (H₁) היא שציוני מכינה א' גבוהים יותר — בדיקה חד-צדדית:

H₀: μ₁ ≤ μ₂ H₁: μ₁ > μ₂

(אוכלוסיה 1 = מכינה א', אוכלוסיה 2 = מכינה ב'.)

חישוב טעות הדגימה. הפרש תוחלות, שונויות אוכלוסיה ידועות — מבחן Z. חד-צדדי במובהקות 5%: z(0.95) = 1.645.

A = z·√(σ₁²/n₁ + σ₂²/n₂) = 1.645·√(400/100 + 225/100)

A = 1.645·√6.25 = 1.645·2.5 ≈ 4.11

הכרעה. אם אין הבדל בין המכינות, הפער הצפוי הוא 0 ומותרת טעות דגימה של עד 4.11 נקודות. הפער בפועל:

x̄₁ − x̄₂ = 72 − 66 = 6 > 4.11

הפער מהותי — דוחים את H₀ ומקבלים את H₁: ברמת מובהקות 5% טענת תלמידי מכינה ב' נכונה, וציוני מכינה א' אכן גבוהים יותר.

סעיף ב

מניחים שמספר התקלות היומי במכונת דפוס מתפלג פואסונית עם ממוצע 1. בודקים זאת לגבי 100 ימי עבודה ומגלים: 40 ימים ללא תקלות, 30 ימים עם תקלה בודדת, 20 ימים עם 2 תקלות ו-10 ימים עם 3 תקלות או יותר. בדוק במובהקות 5% האם ההתפלגות אמנם פואסונית עם ממוצע 1. פרט את ההשערות.

השערות. במבחן טיב התאמה H₀ תמיד מאשרת את ההתפלגות הנבדקת:

H₀: X ~ Poisson(λ = 1) H₁: לא כן

חישוב הצפוי. לפי P(x) = e^(−λ)·λˣ/x! עם λ = 1 (e⁻¹ = 0.3679), מוכפל ב-100 ימים:

P(0) = e⁻¹ = 0.3679 ⇒ E₀ = 36.79

P(1) = e⁻¹·1/1! = 0.3679 ⇒ E₁ = 36.79

P(2) = e⁻¹·1/2! = 0.1839 ⇒ E₂ = 18.39

פואסון היא התפלגות אינסופית — המחלקה האחרונה היא "3 ומעלה", ומשלימים בה את הצפוי לגודל המדגם:

E₃₊ = 100 − 36.79 − 36.79 − 18.39 = 8.03

סטטיסטי המבחן.

χ² = Σ(O − E)²/E

χ² = (40−36.79)²/36.79 + (30−36.79)²/36.79 + (20−18.39)²/18.39 + (10−8.03)²/8.03

χ² = 0.28 + 1.25 + 0.14 + 0.48 = 2.16

הכרעה. 4 מחלקות, והממוצע λ = 1 נתון בשאלה (לא נאמד מהמדגם) — ולכן דרגות החופש הן df = 4 − 1 = 3:

χ²(3, 0.95) = 7.81 > 2.16

הסטיות קטנות מערך הטבלה — מקבלים את H₀: ברמת מובהקות 5% אין לדחות את ההנחה שמספר התקלות מתפלג פואסונית עם ממוצע 1.

שימו לב: אילו λ לא היה נתון והיינו אומדים אותו מהמדגם, היינו מורידים דרגת חופש נוספת — df = 2.
